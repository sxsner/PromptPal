PromptPal（提示词快捷工具）使用说明
========================================

一、启动
  1. 双击 PromptPal.App.exe 即可运行（绿色免安装，已内置 .NET 运行时，
     目标电脑无需安装任何环境；仅支持 64 位 Windows 10/11）。
  2. 首次启动自动建库并写入内置示例：系统 / 编程 / 文档 3 个分类、
     9 条示例提示词、8 个常用标签，可直接查看、修改或删除；
     应用内「设置 → 数据管理 → 重置所有数据」可随时恢复这套初始内容。
  3. 启动后程序驻留系统托盘，可在
     Windows「设置 → 个性化 → 任务栏 → 选择哪些图标显示在任务栏上」
     中决定是否直接显示（身份固定为 PromptPal，设置会被系统记住）。
  4. 全局热键 Ctrl + Shift + P 随时呼出主窗口，窗口在前台时再按一次
     即隐藏回托盘；任务栏最小化状态下按热键也可正常还原。
     如热键被其他软件占用，可在「设置」中关闭热键。
  5. 关闭主窗口不会退出程序，右键托盘图标可退出。
     注销/关机时程序会正常放行，不会阻止系统关机。

二、日常使用
  - 单击列表中的提示词查看详情，点「复制提示词」把正文写入剪贴板；
    也可以直接双击列表项快速复制。
  - 复制成功后底部状态栏会短暂提示，不再弹大提示框、不会顶动布局。
  - 复制后默认自动隐藏到托盘（可在「设置」中关闭该行为），
    每次复制自动累计使用次数。
  - 顶部筛选：全部 / 收藏 / 最近。点详情右上角星标即可收藏/取消，
    左侧列表会即时出现/移除蓝色星标（位置固定，不会让标题跳动）。
  - 排序方式有三种，可随时切换：
      频率：收藏的排最前，然后按最近使用、创建时间排序
      更新：按最后修改时间从新到旧
      名称：按标题拼音/字母排序
  - 复制、收藏、切换排序后，当前选中的提示词和右侧详情保持不变。
  - 外观：「设置 → 通用设置 → 外观」可选浅色 / 深色 / 跟随系统，
    以及小 / 默认 / 大三档字号（切换立即生效，无需重启）；
    主窗口与设置窗口的大小、位置都会自动记忆，下次启动原样恢复。
  - 主窗底部图钉按钮可让窗口固定在最前。

三、数据与日志位置（全部在当前用户目录，换电脑可直接拷贝迁移）
  %LOCALAPPDATA%\PromptPal\
    promptpal.db        全部提示词、分类、标签数据（SQLite）
    settings.json       应用设置（含窗口位置、主题、字号等）
    logs\               运行日志目录，每天一个文件：
      PromptPal-yyyy-MM-dd.log    应用日志（排障首选）
      mcp-yyyy-MM-dd.log          MCP 服务日志
    （跨午夜自动切换到新日期文件；设置「关于」页直接显示日志路径，
      可点「打开数据目录」一键打开该目录。）
  关闭日志的方法：
    应用日志：在 PromptPal.App.exe 同目录放一个空文件 nolog.txt，
              或设置环境变量 PROMPTPAL_LOG=0
    MCP 日志：在 mcp\PromptPal.Mcp.exe 同目录放空文件 nolog.txt，
              或设置环境变量 PROMPTPAL_MCP_LOG=0

四、备份与换机（直接导出/拷贝 .db 数据库文件即可）
  方式 A（推荐，最省心）：应用内「设置 → 数据管理」
    - 导出 .db：程序运行中也可导出，生成的是单个完整、一致的
      数据库快照文件（不依赖任何附属文件），文件名类似
      promptpal-20260916-1430.db。
    - 导入 .db：选择此前导出的 .db，会整体替换当前数据，导入前
      自动在数据库旁生成 promptpal.db.bak_时间 备份（保留最近 5 份）。
      导入会校验文件是否为本程序数据库，选错文件会被拒绝，数据不动。
  方式 B：手动复制数据库到新设备
    1. 旧电脑：先彻底退出本程序（托盘图标右键 → 退出）；
       如果正在用 Trae 等 MCP 客户端，也请关闭客户端（它驻留的
       mcp 服务会占用数据库）。
    2. 确认 %LOCALAPPDATA%\PromptPal\ 目录下 promptpal.db-wal 和
       promptpal.db-shm 已随退出自动消失，然后只复制 promptpal.db
       这一个文件即可（它们消失说明最新数据已全部写入主库）。
       若这两个文件还在，请把 db、db-wal、db-shm 三个文件一起复制。
    3. 新电脑：先把本程序至少启动一次再退出（会自动建好目录与权限），
       打开 %LOCALAPPDATA%\PromptPal\，把里面的 promptpal.db 以及
       promptpal.db-wal、promptpal.db-shm（如果有）全部删除后，
       再放入旧电脑的 promptpal.db，然后启动程序。
       （也可以在首次启动前就把 promptpal.db 放进该目录，目录不存在
         可手动新建为 %LOCALAPPDATA%\PromptPal\，首次启动会自动收敛权限。）
    重要：不要在程序运行时复制，也不要只替换 promptpal.db 而留下
    旧的 promptpal.db-wal/-shm——未提交完的缓存会覆盖你新放进去的库。
  注意：数据库结构随程序版本演进，旧版本导出的库在新版程序上一般
  可直接使用；跨多个大版本迁移若提示结构不一致，请先用旧版导出、
  再用新版「导入 .db」识别。

五、分类管理
  「设置」→ 分类管理页，每个分类是一张可拖拽卡片：
    - 调整顺序：按住卡片直接上下拖动到目标位置即可，左侧 ⋮⋮ 是
      拖拽提示；键盘用户可选中卡片后用 Alt+Shift+↑/↓ 调整。
    - 添加：在下方输入名称后点「添加」，或直接按回车（名称最长 64 字），
      新分类自动排在末尾
    - 重命名：点该卡片上的「重命名」按钮（同名不允许，名称自动去空格）
    - 删除：点该卡片上的「删除」。删除分类不会删掉其中的提示词，
            这些提示词会变为「未分类」，仍可正常使用
  分类顺序与名称在 MCP 中同步生效（MCP 侧可用 move_category 工具排序）。

六、接入 MCP（供 Trae 等支持 MCP 的 AI 客户端调用）
  本包 mcp 子目录内的 PromptPal.Mcp.exe 是独立自包含的 MCP stdio 服务，
  无需在目标电脑安装 .NET。
  注册步骤（以 Trae 为例，二选一）：
    1. 打开应用内「设置」→ 左侧「MCP 接入」→
       点「复制注册配置（mcp.json）」；
       方式 A：打开 Trae 的 MCP 面板 → 添加 → 选 stdio →
               命令粘贴为 mcp\PromptPal.Mcp.exe 的完整路径；
       方式 B：把复制的配置保存为项目根目录下的 .trae\mcp.json。
    2. 在 Trae 中执行 Reload Window（Ctrl+Shift+P → Reload Window），
       首次使用按提示信任即可。
  设置页会显示服务路径、就绪状态和全部工具清单。

  共 13 个工具：
    list_categories    列出全部分类（含每个分类下提示词数量）
    list_tags          列出全部标签（含使用次数）
    search_prompts     按关键词/分类/标签/收藏状态搜索提示词
    get_prompt         读取单条提示词完整内容
    copy_prompt        取用提示词：返回完整正文供 AI 对话直接使用，
                       同时累计使用次数；不操作剪贴板
                       （写剪贴板请用应用内的「复制提示词」按钮）
    create_prompt      新建提示词（标题/内容/分类/标签）
    update_prompt      修改提示词
    toggle_favorite    切换收藏
    delete_prompt      删除提示词
    create_category    新建分类（自动排到末尾）
    rename_category    重命名分类
    move_category      分类上移/下移（参数 direction: "up"/"down"）
    delete_category    删除分类（仅解绑，不删除其中提示词）

七、常见问题
  1. 双击没反应或闪退：打开 %LOCALAPPDATA%\PromptPal\logs\，
     把当天的 PromptPal-yyyy-MM-dd.log（必要时连同
     mcp-yyyy-MM-dd.log）一起反馈即可定位。
  2. 托盘图标不见了：通常是资源管理器重启所致，程序会自动重新注册；
     如仍异常，退出程序后重新启动即可（数据不受影响）。
  3. MCP 客户端连不上：确认注册配置里的路径指向本包 mcp 目录下的
     PromptPal.Mcp.exe（移动本文件夹后需重新复制配置），查看
     logs\mcp-当天日期.log。
  4. 手动换机后数据没变化/是旧数据：多半是只替换了 promptpal.db 但
     残留了旧的 promptpal.db-wal/-shm，或复制时程序没退出。按第四部分
     方式 B 重做即可；应用内「导入 .db」不受此问题影响。
  5. 本程序不写系统注册表（仅保存自己的用户数据与窗口偏好），
     卸载/删除：直接删除整个文件夹即可
     （数据文件如需清理请手动删除上面的 PromptPal 数据目录）。
